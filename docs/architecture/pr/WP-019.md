## WP-019 — Size positions from calibrated probability with an unlock rule (ADR-006)

### Why
All 334 paper positions are the same size. The sizer's confidence input was the raw screening score,
which is at least 65 for every discovery call, so every call cleared the HALF tier. The size said
nothing about evidence.

### What changed
- **`agents/position_sizer.py` — `size_from_probability(hit_rate, band_n, lower_bound, action)`**
  - **BASE** (2.5 %, ₹5,000 in the paper book, what every position has had) for every call.
  - **CONVICTION** (5 %, ₹10,000) **unlocks only for a band** whose 90 % Wilson lower bound on the
    beat-Nifty rate exceeds **55 %** with **n ≥ 30** resolved, independent calls.
  - SELL/AVOID get 0.
  - Each result carries `sizing_rationale` ("Conviction sizing locked — only 17 resolved calls…" /
    "…lower bound 39.2 % does not exceed 55 %") and `conviction_locked`.
  - `calc_position_size` stays for the legacy `DECISION_SOURCE='llm'` path.
- **`agents/call_calibration.py`**: `wilson_lower(hits, n, z)`, plus `Calibration.band()` and
  `Calibration.lower_bound(score)`. The bound uses the band's **raw** hits/n, not the shrunk rate,
  because the rule asks whether *that band* has proved an edge.
- **`data/decision_config.py`**: `SIZING_UNLOCK_LOWER_BOUND = 55`, `SIZING_UNLOCK_MIN_N = 30`,
  `SIZING_Z`, `BASE_POSITION_PCT = 2.5`, `CONVICTION_POSITION_PCT = 5.0`.
- **`agents/discovery_screener.py`**
  - The new `_size_discovery()` passes the **calibrated rate, band n and lower bound** for the
    call's band, not the raw score.
  - It runs in `run_discovery` for every promoted call, so dry runs log it too:
    `<SYMBOL> sizing: BASE (conviction locked) — …`.
  - `_save_discovery` reuses the result and stores `sizing_tier`, `sizing_rationale`,
    `conviction_locked` and `sizing_lower_bound` in metadata.
  - The CRITICAL-only warren_bot call that existed solely to reach the old FULL tier is gone.
- **`scheduler/orchestrator.py`** (outside `touches`): WP-018 has landed, so code-decided portfolio
  calls now size with the same rule from the composite-band calibration. This replaces WP-018's
  interim "size on the composite". The sizing record is in `metadata.decision.sizing`.
- **`agents/paper_portfolio.py`**: `base` → ₹5,000 and `conviction` → ₹10,000 allocations. Legacy
  labels are unchanged.
