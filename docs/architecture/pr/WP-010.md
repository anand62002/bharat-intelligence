## WP-010 — Make swallowed failures loud on the decision path (ADR-005)

### Why
The decision path still hid failures. Examples: position sizing and warren_bot sizing in
`_save_discovery`, the earnings guard and leakage audit in synthesis, and the alert dedup checks in the
portfolio monitor. A failure there changes the recommendation, its size or its alerts, and nothing
recorded it.

### What changed
**29 silent handlers made loud, with control flow unchanged.** Every failure that was non-fatal stays
non-fatal and returns the same fallback; it now logs a WARNING naming the symbol and the exception.

| File | Sites | Notes |
|---|---|---|
| `scheduler/orchestrator.py` | 4 | governance screener, sector macro adjust, **leakage audit and earnings guard also append to the run's `errors` list** → the orchestrator's `daily_runs` row records them (status WARNING) |
| `agents/discovery_screener.py` | 9 | live sector-PE median, pre-screen earnings guard / liquidity / DVM, sector macro adjust, warren_bot sizing, **position sizing**, impact cost, forward estimates |
| `agents/target_updater.py` | 6 | warren cache write, quick technicals, sector PE, and three unparseable-date cooldown checks (now name the holding and the bad value) |
| `agents/outcome_tracker.py` | 2 | symbol-map lookup, per-symbol batch price |
| `agents/paper_portfolio.py` | 2 | symbol-map lookup, per-symbol batch price |
| `scheduler/portfolio_monitor.py` | 6 | **outside `touches`**: both alert dedup checks (a failure silently allowed duplicate alerts), latest-rec fetch, correlation download, FII 5-session, news check. These decide alerts; added to reach the ≥25 target, since the five listed files held only 23 sites. |

Only the sites that run inside a job with an `errors` list in scope (`synthesise_node`) report there.
The others are helpers with no such list; their WARNING goes to the worker log.

- **`tests/exception_allowlist.txt`**: the 29 sites removed (regenerated with `--write`; the diff is deletions only). **173 → 144.**
- **New `tests/test_loud_failures.py` (6)**: discovery sector PE, the outcome-tracker and paper-portfolio symbol maps, target-updater sector PE and portfolio-monitor alert dedup. Each forces the handler to fire and asserts the WARNING plus the unchanged fallback. Another test confirms both `synthesise_node` sites append to `errors`.

### Risk
Medium, as rated in the plan, though in practice it's log volume.
- The pre-screen sites run for ~200 symbols a day, so a broken dependency (e.g. the earnings calendar) now produces up to 200 WARNING lines instead of none. That's the visibility the change is for.
- The orchestrator run reports WARNING on days the earnings guard or leakage audit fails. The WP-006 watchdog accepts WARNING.
