## WP-012 — Create the candidates ledger table (ADR-002)

### Why
The system learns only from promoted calls (~15 independent labels a month) while discovery
screens 200 symbols a day and throws away what it computed. ADR-002 makes an append-only
`candidates` table the single learning dataset. This package creates the table; WP-013 writes to it.
