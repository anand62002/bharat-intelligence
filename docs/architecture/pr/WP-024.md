### Risk
Low. Breeze *was* configured in production: the job ledger shows the 08:35 job reporting
"Token present" in manual mode every day. But it **never served data**: the 15:45 options snapshot's
ledger rows show `source: "fallback"` (India VIX) for NIFTY on every day from 2026-11-15 to 2026-11-21.
So the token was set but not usable. Removing it changes nothing observed beyond one daily job fewer,
and options metrics still come from Trendlyne → NSE → VIX.

**Separate finding (needs you, not code):** options metrics have run on the VIX **fallback** every day, so
neither Trendlyne F&O nor NSE has been serving them. A read-only probe of `data/trendlyne_fno_fetcher`
returns `File is not a zip file` for both NIFTY and RELIANCE. The F&O download is coming back as a web
page, not the Excel file, which is what an expired or missing `TRENDLYNE_SESSION` / `TRENDLYNE_CSRF`
cookie produces. Refresh those two cookies on Railway, or set `TRENDLYNE_USER` / `TRENDLYNE_PASS` for
the auto-refresh, to restore real option-chain metrics. NSE is blocked from Railway by design.
