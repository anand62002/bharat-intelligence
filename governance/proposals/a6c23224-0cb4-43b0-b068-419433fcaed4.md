## Abstract

arXiv:2610.03080v1 Announce Type: cross 
Abstract: Large language models are moving from producing trading signals to writing the code that executes them. The failure mode of the second role is silent: generated code runs, a backtest plots, yet the risk logic that the trader described is not the logic being executed. Existing code benchmarks test functional correctness on unit tests and finance benchmarks test forecasting; neither measures whether an implementation behaves like the strategy that was asked for. We introduce MintEval, a benchmark in which reference strategies are generated programmatically from a library of composable building blocks, back-translated into colloquial trader instructions, and re-implemented by the model under test. ## Proposed Change

Add a strategy validation layer in orchestrator/synthesis.py that executes a 'dry-run backtest' comparing the LLM-synthesized recommendation against a simplified rule-based implementation of the same logic. For each synthesis output (BUY/HOLD/SELL), generate a minimal Python function expressing the decision rule (e.g., 'if RSI<30 and MACD_cross_up then BUY'), execute both on the last 20 bars of historical data, and flag mismatches where action sequences differ by >20%. This catches hallucinated logic before capital allocation, inspired by MintEval's action-match methodology.
