## Abstract

arXiv:2606.22719v1 Announce Type: new 
Abstract: Forecasting benchmarks for retrieval-augmented LLMs routinely confound model capability with information leakage: features labeled with a target's timestamp are often not observable at the system's decision time. We study leakage-controlled equity factor ranking with a retrieval-augmented 7B open-source LLM forecaster. At each month-end from 2023-04 to 2026-03, the forecaster observes only decision-time information: lag-shifted FRED macro variables, recent macro-event summaries, and the Cleveland Fed's archived daily CPI nowcast for unreleased current-month inflation. ## Proposed Change

Add a `leakage_guard` module in `agents/macro.py` that timestamps all FRED and RBI data retrieval, then enforces a 2-business-day publication lag before features are observable to the orchestrator (e.g., March CPI released April 12 becomes available April 16). Modify `macro_agent.analyze()` to replace unavailable current-month values with a retrieval-augmented nowcast: retrieve 5 most similar historical macro states (CPI YoY, repo rate, INR-USD) via pgvector embedding similarity, then prompt Claude Haiku to generate a point nowcast with confidence interval.
