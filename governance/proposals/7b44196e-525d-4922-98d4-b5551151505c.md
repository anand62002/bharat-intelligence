## Abstract

arXiv:2610.31916v1 Announce Type: new 
Abstract: A durable agent can resume a consequential action while its authority changes and the action's external outcome remains uncertain. We study execution-time reliability of tool-using AI agents, isolating recovery decisions from language-model behavior. Checkpoint state, permission to dispatch, evidence of an external effect and permission to reconcile are distinct obligations. We present a finite conformance study that checks these obligations through histories scored against a provider effect ledger hidden from the recovering application. A prospectively frozen campaign executes 336 histories on native LangGraph and Temporal hosts, crossing 14 schedules, three provider contracts and four matched application policies. ## Proposed Change

Add checkpoint-based retry logic to orchestrator/synthesizer.py by implementing a LangGraph checkpointer (MemorySaver or PostgresSaver) that persists agent execution state before each agent call. Wrap each agent invocation in a try-except block that checks authorization state (e.g., API rate limits, Screener.in session validity) and implements exponential backoff retry with permission revalidation (re-checking API keys/tokens) before retrying failed agents. This prevents cascading failures when individual data sources are temporarily unavailable and ensures the synthesis step can resume from the last successful agent checkpoint rather than re-executing all 7 agents.
