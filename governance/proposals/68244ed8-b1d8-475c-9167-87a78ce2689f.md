## Proposed Change

Add a multi-hop evidence chain verification module to agents/fundamental.py that creates a local mini-KG from Screener.in data (company fundamentals → peer comparisons → sector averages → temporal changes). When fundamental_agent returns a signal, construct 2-3 hop evidence paths (e.g., 'Reliance PE=25 → Sector median PE=18 → YoY sector PE increased 12%') and store them as a typed graph structure in the detail dict. This enables the governance fact_checker to traverse provenance chains and detect hallucinated intermediate reasoning steps, directly addressing the paper's finding that LLM performance degrades when evidence structure changes.
