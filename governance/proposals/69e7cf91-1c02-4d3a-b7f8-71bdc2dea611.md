## Abstract

Abstract: Language agents increasingly work for users on the open Web, and finance is where trusting them is hardest. The data must come from the Web, the strategy lives in the user's head, and correctness depends on time, so an agent can fail silently: a strategy the user never asked for, unverified data, or a backtest that uses the future yields a report as convincing as a correct one. Existing benchmarks close the world somewhere, fixing the task, the data, or the timeline, and thereby remove these failures instead of measuring them. We introduce FINCOSMOS, an open-world evaluation paradigm for agents doing financial work. ## Proposed Change

Add a `data_provenance_tracker` module that records fetch timestamps, source URLs, and data cutoff dates for all external data retrieval (yfinance, Screener.in, NSE/BSE, RSS feeds). Modify each agent's return dict to include `data_cutoff: datetime` and `source_urls_with_timestamp: list[dict]`. In orchestrator/synthesizer.py, implement a point-in-time verification function that flags any agent using future data relative to the analysis date, rejecting synthesis if temporal leakage is detected (inspired by FINCOSMOS's data cutoff enforcement).
