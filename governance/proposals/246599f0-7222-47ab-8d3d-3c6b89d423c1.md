## Abstract

Language model agents often abandon correct work when a user challenges it, yet simply telling them to stand firm makes them ignore real mistakes. Once an agent reads a complaint, it tends to discount its own earlier checks in order to agree with the user. We introduce Thinking-in-Bets, a training-free method in which an agent writes a short private record of its main claims, the checks supporting them, and its confidence before reading user feedback. When challenged, the agent consults this Claim Checklist to keep verified work intact while investigating uncertain or newly challenged parts. ## Proposed Change

Add a `claim_checklist` phase to `orchestrator/synthesis.py` where Claude Sonnet records each agent's signal, score, and top 3 supporting facts (e.g., 'RSI=28.4 oversold', 'PE=18.2 vs sector 24.5') BEFORE the final synthesis step. When fact_checker or human feedback challenges a recommendation, modify the synthesis prompt to reference this pre-recorded checklist, instructing the model to preserve claims with strong evidence scores (>70) while re-evaluating only low-confidence (<50) or directly contested points. This prevents the orchestrator from abandoning valid technical/fundamental signals when challenged by contradictory sentiment or macro data.
