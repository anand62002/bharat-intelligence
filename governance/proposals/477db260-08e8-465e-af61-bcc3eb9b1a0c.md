## Abstract

arXiv:2607.18240v1 Announce Type: new 
Abstract: Large language models (LLMs) can achieve strong fact-checking accuracy, yet forced binary decisions conceal a critical reliability problem: systems may issue confident verdicts even when supporting evidence is weak, sparse, or internally inconsistent. We address this issue through Evidence Chain Evaluation (ECE), a selective fact-checking framework that permits abstention via an uncertain verdict instead of requiring a true/false decision for every claim. The evaluated system is a tool-using verification agent that gathers evidence through web search, scholarly search, and executable checks, and then returns a structured verdict with confidence and source-level metadata. ## Proposed Change

Extend governance/fact_checker.py to implement selective fact-checking with abstention. Add a confidence_threshold parameter (default 0.75) and return {verdict: 'VERIFIED'|'FALSE'|'UNCERTAIN', confidence: float, evidence_chain: list} instead of binary true/false. When confidence < threshold, return 'UNCERTAIN' and defer to human review queue in Supabase. This mirrors the paper's ECE framework, allowing the system to maintain 95%+ accuracy on answered claims while abstaining on ~6% of low-evidence cases.
