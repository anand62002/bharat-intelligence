## Abstract

Abstract: Multi-agent AI workflows are limited not only by model quality but by token cost, latency, and context-window quality. This paper presents a practitioner framework for token optimization and context-window management, grounded in an internal production dashboard that extracts structured work items from meetings, email, and chat with LLMs and routes summaries across workstreams. Six patterns are described: context stratification, fetch-once/process-locally architecture, schema-contracted prompts, token-aware fallback chains, semantic caching, and inter-agent communication compression. ## Proposed Change

Implement context stratification in orchestrator/synthesizer.py by adding a _stratify_agent_outputs() method that bins agent responses into critical (signal='BUY'/'SELL', score>80), supporting (score 50-80), and context (score<50) tiers. Modify the synthesis prompt to include full detail dicts only for critical tier, truncated summaries for supporting tier, and omit context tier from the LLM call while logging them separately. This directly applies the paper's context-composition finding: removing low-relevance items from the prompt improves model concordance on high-relevance items.
