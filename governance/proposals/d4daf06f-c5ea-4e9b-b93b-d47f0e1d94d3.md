## Proposed Change

Introduce a deterministic Executive class in orchestrator/langgraph_workflow.py that owns all final decisions, while agents (technical, fundamental, sentiment, institutional, macro, commodities, historical_rag) return only typed proposals with pre-registered predictions. Before executing any signal (BUY/HOLD/SELL), the Executive logs a prediction hash (expected_price_range, expected_metric_values) to Supabase, then post-execution verifies actual market data against the pre-registered prediction. If verification fails (e.g., claimed RSI 30 but actual 65), the run self-invalidates and logs the discrepancy for performance_tracker audit.
