## Abstract

Demonstrates that advanced RAG techniques measurably improve retrieval accuracy, answer quality, latency, and cost in financial QA.

## Proposed Change

Upgrade agents/historical_rag.py to implement small-to-big retrieval by storing fine-grained child chunks (sentence-level, ~100 tokens) in the pgvector table with a parent_chunk_id foreign key linking to larger parent chunks (~512 tokens). Modify the retrieve_similar_analysis() function to: (1) embed and search against child chunks for precise semantic matching, then (2) fetch the full parent chunk context before passing to the LLM synthesiser. This replaces the current flat single-chunk retrieval with a two-stage fetch that improves both recall precision and answer coherence for complex multi-factor Indian stock queries.
