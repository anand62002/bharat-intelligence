## Abstract

Multi-agent LLM systems improve reasoning by combining outputs from multiple agents, but interaction-heavy methods can introduce error propagation and high communication overhead. When agents exchange raw responses or reasoning traces, incorrect intermediate reasoning may be adopted and amplified, leading to confident but wrong consensus; multi-round communication also increases token consumption, latency, and inference cost. In this paper, we propose a controlled-communication coordination framework named DarkForest. DarkForest first keeps agents independent, so each agent produces an answer without seeing the others' outputs. ## Proposed Change

Modify orchestrator/langgraph_coordinator.py to implement DarkForest's independent-then-cluster pattern. Change the workflow so all 7 agents execute in parallel without seeing each other's outputs (currently they may share context). Add a new clustering step that groups semantically similar signals (e.g., multiple BUY signals with similar reasoning) using sentence-transformers cosine similarity on the 'detail' field, then weight each cluster by agent reliability scores (tracked by performance_tracker). Replace the current Claude Sonnet synthesis prompt with a structured belief distribution that shows cluster frequencies and confidence-weighted scores, limiting the LLM coordinator to only high-confidence clusters (>0.6 threshold) to reduce error propagation.
