Abstract: Missing and misleading evidence are not the same problem in retrieval-augmented generation (RAG), but prompt-based abstention treats them alike. Small frozen models abstain when context is absent, not when it is misleading. We introduce GRAB-RAG (Graded Abstention Benchmark for Retrieval-Augmented Generation), a paired benchmark that tests the same questions across four context conditions (supportive, degraded, missing, and misleading) in Natural Questions and HotpotQA. In the misleading condition, we edit a gold passage to support a wrong answer and place it among other retrieved passages. ## Proposed Change

In `governance/fact_checker.py`, add a `misleading_context_detector()` function that runs an NLI-based cross-passage consistency check on the RAG context retrieved by `agents/historical_rag.py` before synthesis. Specifically, for each retrieved passage used as evidence, compare its core claim against the other retrieved passages using a lightweight NLI verifier prompt (via Claude Haiku) that flags inter-passage contradictions — not just missing evidence. When a conflict score exceeds a configurable threshold (e.g., cosine similarity < 0.4 between conflicting claims), the fact_checker should annotate the historical_rag agent's output with a `context_conflict: true` flag and downweight its score by 30% in the LangGraph orchestrator's synthesis step (`orchestrator/daily_synthesis.py`), rather than discarding it entirely (avoiding the coverage loss identified in the paper).
