## Abstract

arXiv:2610.04040v1 Announce Type: cross 
Abstract: Financial LLM agents are often evaluated by comparing their end-to-end returns with those of a baseline and testing the paired difference against zero. This measures whether deploying the agent changes realized performance, but it does not isolate event-selection skill. An agent that frequently changes positions from flat to long can earn a positive paired return from an upward-drifting event pool even when it selects events at random. We propose the Agent Policy-Value Audit, which holds fixed the observed count of each ordered action-change type and randomly reassigns them across eligible events. ## Proposed Change

Add a new governance module 'governance/policy_value_auditor.py' that retroactively audits the orchestrator's BUY/SELL/HOLD transitions by permuting them across eligible stocks while holding transition counts fixed. Each week, sample the last 30 days of agent recommendations, extract action-change sequences (e.g., HOLD→BUY, BUY→SELL), randomly reassign these transitions to stocks that were eligible for that transition, compute the counterfactual return distribution (composition benchmark), and compare observed returns to isolate genuine selection skill vs. passive drift exposure.
