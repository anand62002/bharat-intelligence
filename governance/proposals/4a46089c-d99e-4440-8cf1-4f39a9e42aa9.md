## Abstract

arXiv:2604.23027v1 Announce Type: new 
Abstract: Large language models (LLMs) have become central to modern AI workflows, powering applications from open-ended text generation to complex agent-based reasoning. However, debugging these models remains a persistent challenge due to their opaque and probabilistic nature and the difficulty of diagnosing errors across diverse tasks and settings. This paper introduces a systematic approach for LLM debugging that treats models as observable systems, providing structured, model-agnostic methods from issue detection to model refinement. By unifying evaluation, interpretability, and error-analysis practices, our approach enables practitioners to iteratively diagnose model weaknesses, refine prompts and model parameters, and adapt data for fine-tuning

Add a structured LLM debugging module (governance/llm_debugger.py) that implements observable system monitoring for all 7 agents. Create a DebugTrace dataclass capturing (agent_name, prompt_template, input_tokens, output_tokens, latency_ms, signal, score, model_response_raw) for each agent invocation. Store traces in Supabase table 'llm_debug_traces' with daily aggregation queries to detect anomalies (e.g., RSI agent consistently returning HOLD when price crosses oversold threshold). Add a weekly diagnostic report function that flags: prompt drift (cosine similarity <0.85 vs baseline), latency spikes (>2σ), score volatility (std_dev >15 within same stock/day), and inconsistent signal patterns (BUY→SELL flip <24hr without news trigger).
