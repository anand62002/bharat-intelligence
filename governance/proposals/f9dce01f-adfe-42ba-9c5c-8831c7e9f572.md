## Abstract

Abstract: When multi-agent LLM systems produce bad answers, not all failures are equal: some answers are grounded in the right material but incomplete, while others are simply ungrounded and should be stopped. Current retry strategies treat both cases identically (try again and hope for the best), leaving human supervisors unable to tell whether a retry was warranted or whether the system should have halted instead.
  We introduce the Argent Signaling Protocol (ASP), a compact machine-readable header that accompanies every AI-generated response with structured quality signals: certainty (@C), grounding (@G), stochasticity (@S), and an assumption index that classifies the evidentiary basis of each claim. ## Proposed Change

Add Argent Signaling Protocol (ASP) headers to all agent responses by modifying the base Agent class in agents/base.py. Each agent's return dict will include new fields: certainty_score (0-100), grounding_sources (list of actual URLs/tickers referenced), stochasticity_flag (bool indicating if result varies on retry), and assumption_index (categorical: [direct_data, derived_calculation, model_inference, external_claim]). The orchestrator in orchestrator/synthesizer.py will use these signals to implement differential retry logic: high-certainty + well-grounded failures trigger parameter adjustment retries, while low-certainty + ungrounded responses are immediately flagged for human review instead of wasting tokens on hopeless retries.
