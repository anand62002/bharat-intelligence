## Abstract

arXiv:2607.20492v1 Announce Type: new 
Abstract: Language models in production do not write prose. They fill forms: JSON fields, function arguments, extraction templates. We show that the form itself causes hallucination.
  We ask thirteen models the same question about the same input and change only the answer format. The inputs are built so the question cannot be answered: a viral post showing 12,400 likes but no visible replies, a support ticket whose call was never transcribed. In free text, GPT-5.5 answers honestly. It says there is no reply data, 98% of the time. Given a required JSON field for sentiment, the same model invents an answer 40 times out of 40. It fabricates the mood of crowds it never saw and quotes customers it never heard.

## Proposed Change

Modify the LangGraph orchestrator's synthesis prompt to include explicit 'INSUFFICIENT_DATA' as a valid signal option alongside BUY/HOLD/SELL/AVOID, and refactor each agent's return schema to make the 'signal' field optional with a new 'data_quality' enum (SUFFICIENT|PARTIAL|INSUFFICIENT). When data_quality=INSUFFICIENT, the orchestrator must return INSUFFICIENT_DATA rather than forcing a tradeable signal, preventing the 'PhantomFill' hallucination where required JSON fields cause fabrication of analysis from missing data.

**Impacted agents**: technical, fundamental, sentiment, institutional, macro, commodities, historical_rag, orchestrator
**File to change**: `orchestrator/synthesis.py`
**Cost impact**: low
