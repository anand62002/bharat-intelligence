## Abstract

arXiv:2606.02965v1 Announce Type: new 
Abstract: Benchmarks for autonomous agents measure whether agents complete tasks, yet this framing is systematically blind to whether an agent should have proceeded at all. Agents trained under human-feedback objectives develop a structural tendency to proceed even when they lack the inputs, evidence, or authorization to act safely, a disposition we term compliance bias, because both the reward signal and the benchmark scoring regime treat proceeding as the correct default regardless of whether the preconditions for safe action are present. We make three contributions. We first show that compliance bias originates in reward hacking within human-feedback pipelines and is entrenched by prominent agent benchmarks, which either penalize agents for pausing

## Proposed Change

Add an abstention layer to the LangGraph orchestrator (orchestrator/synthesizer.py) that explicitly evaluates three gap types before emitting final signals: (1) specification gaps (missing fundamental data like PE ratio or technical indicators due to API failures), (2) verification gaps (data staleness >24hrs or conflicting signals across 3+ agents with score variance >40), and (3) authority gaps (stocks outside Nifty 500 or penny stocks <₹10). When any gap is detected, return a new signal type 'ABSTAIN' with gap_type and missing_preconditions metadata instead of forcing BUY/HOLD/SELL, and track abstention accuracy weekly via performance_tracker to measure whether abstained stocks would have triggered stop-losses.

**Impacted agents**: orchestrator, performance_tracker

## Expected Improvement

Reduce false-positive trades by 15-25% by preventing signals when preconditions are unmet, measured as percentage decrease in recommendations that hit stop-loss within 7 days for abstained vs. non-abstained stocks with similar initial conditions
