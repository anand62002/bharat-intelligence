## Abstract

arXiv:2611.18934v1 Announce Type: new 
Abstract: Papers on large-language-model (LLM) trading agents and alpha mining report Sharpe ratios that would be remarkable in any other part of empirical finance. We audit the evidence behind those numbers. Before coding a single paper we pre-registered a population of 91 papers from a curated corpus of LLM trading research, a ten-field coding rubric, an analysis script and five directional hypotheses, and committed all of them to version control. Every code is backed by a verbatim quote that a script checks against the paper's text, and a second, blind coder recoded a random 20%. ## Proposed Change

Add a `BacktestIntegrityChecker` class to `governance/hallucination_detector.py` that runs weekly alongside the existing audit. It will (1) flag any agent signal whose back-tested score was computed over a window shorter than 252 trading days, logging a WARNING; (2) cross-check the LLM model training cutoff stored in a new `config/model_registry.json` (fields: model_name, training_cutoff_date) against the earliest date in the test window for every synthesis run persisted in Supabase's `synthesis_log` table, raising a `LeakageRiskError` if test_start < training_cutoff; (3) verify that all performance_tracker outcome calculations in `governance/performance_tracker.py` subtract a fixed transaction cost of 0.1% per leg (NSE brokerage + STT estimate) before computing accuracy/Sharpe, enforced via a mandatory `net_of_costs: bool` field in the `PerformanceRecord` Pydantic model that must be `True` or the record is rejected. These three controls directly address the audit paper's finding that 51% of LLM trading papers omit costs and 56% have leakage risk from short/pre-cutoff windows.
