## Proposed Change

Add a Python-based numerical validator to the fact_checker governance module that intercepts all computed ratios (PE, ROCE, debt_equity, RSI, MACD signal-line, ADX) before they reach the final synthesis. Specifically, in governance/fact_checker.py, add a function `validate_computed_numbers(agent_outputs: list[dict]) -> list[dict]` that re-computes each numeric claim using raw data already fetched by the agent (stored in `detail` dict) via pure Python arithmetic, then flags any discrepancy above a 2% tolerance as a hallucination with a corrected value. This directly mirrors FinVeriQA's finding that Python computed 100% of financial calculations correctly vs. 29% for LLMs, and prevents Claude Sonnet from propagating LLM-miscalculated ratios into the final BUY/SELL signal. The validator should also enforce citation provenance: each numeric in the synthesis must map back to a named data_source field from the originating agent, raising a warning if the reference is absent.
