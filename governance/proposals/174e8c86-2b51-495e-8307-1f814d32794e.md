## Abstract

Abstract: Tool-using LLM agents repeatedly face decision points under uncertainty, choosing between autonomous action, additional information gathering, and human escalation. These decisions require balancing task success against interaction cost and the risk of irreversible errors. Learning to make these trade-offs is challenging because existing interaction trajectories record only the outcomes of actions taken, leaving the consequences of alternative actions unobserved. To address this gap, we construct a counterfactual dataset containing 3,115 action outcomes from 1,036 decision points in ToolSandbox. ## Proposed Change

Add a `DecisionController` class in `orchestrator/decision_controller.py` that implements SURE-Act's action-selection logic. At each orchestration step, before executing agent calls, the controller evaluates 3 alternatives: (1) proceed with all 7 agents, (2) escalate high-uncertainty stocks to human review (flag in output), (3) gather additional data via research_agent. Train a lightweight ranker (scikit-learn RandomForest, <1MB) on historical decisions using features: agent score variance, data_source overlap count, sentiment polarity spread, and historical accuracy for that stock. Controller selects the action maximizing expected utility (task_success - 0.1*interaction_cost - 5*irreversible_error_risk).
