## Proposed Change

Add a DataCompletenessValidator class in agents/base.py that each agent must call before generating signals. It checks if required data fields (e.g., PE ratio for fundamental, volume for technical) are present and meet minimum quality thresholds. If critical data is missing, agents return a new signal type 'INSUFFICIENT_DATA' with a completeness_score (0-100) and missing_fields list, preventing hallucinated analysis on incomplete information.
