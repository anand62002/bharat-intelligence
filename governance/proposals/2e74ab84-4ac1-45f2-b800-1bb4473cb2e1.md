Abstract: Multi-agent systems (MAS) built on large language models are typically organized around roles, pipelines, and turn schedules, while the content that agents pass to one another is often left as unconstrained natural language. However, this free-form communication can rapidly inflate token usage, consume the shared context window, and ultimately affect both system performance and inference cost. We analyze five common inter-agent communication strategies across two MAS topologies, finding that no fixed strategy is universally optimal. ## Proposed Change

Add a structured action-state protocol layer in orchestrator/langraph_synthesis.py by creating a compress_agent_output() function that transforms each agent's raw dict response into a compact action-state record (signal, score, top-3 key-value pairs from detail, agent_name) before appending to shared LangGraph state. This implements PACT's core insight: preserve only action-centered information (the trading signal + critical supporting data) while discarding verbose explanations that bloat the context window during multi-agent synthesis.
