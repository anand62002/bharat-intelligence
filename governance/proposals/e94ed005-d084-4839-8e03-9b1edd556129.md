## Proposed Change

Add a trust scoring mechanism to the LangGraph orchestrator (orchestrator/synthesis.py) that validates inter-agent signal consistency before final synthesis. Implement a trust matrix that flags semantic misalignment (e.g., technical agent says BUY with score 85 while fundamental says AVOID with score 20) and downgrades confidence when agent agreement is <40%. This prevents cascading failures from adversarial or hallucinated agent outputs before they reach the synthesis layer.
