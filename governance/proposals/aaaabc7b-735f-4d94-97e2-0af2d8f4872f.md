## Abstract

arXiv:2610.21113v1 Announce Type: cross 
Abstract: Large-scale multi-agent ecosystems require mechanisms for discovering suitable agents without exposing entire registries to a large language model (LLM) orchestrator. The challenge is not only to retrieve relevant Agent Cards from a growing registry, but also to maintain a compact candidate context, since each additional candidate increases prompt size, inference cost, latency, and the risk of exceeding the model context window. We formulate this problem as candidate-context scalability and propose the Structural Signal Retriever (SSR), our deterministic and training-free retrieval method designed for Agent Card discovery. ## Proposed Change

Implement SSR-based agent discovery in the LangGraph orchestrator (orchestrator/daily_synthesis.py) by creating an inverted index mapping capability signals (e.g., 'technical_RSI', 'fundamental_PE', 'sentiment_RSS', 'macro_RBI_rate') to agents. Before LLM synthesis, parse the user query/stock ticker to extract relevant signals (e.g., 'volatility' → technical_agent + macro_agent), score agents using TF-IDF on their capability descriptors, and invoke only top-3 agents instead of all 7. This reduces Claude Sonnet input tokens by ~57% (4 agents eliminated) and orchestration latency proportionally, while maintaining accuracy for focused queries.
