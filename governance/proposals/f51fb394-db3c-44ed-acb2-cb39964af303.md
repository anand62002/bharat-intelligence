## Proposed Change

Add a multi-task verification pipeline in orchestrator/daily_synthesis.py that creates a unified evaluation interface mirroring OpenFinGym's approach. After each agent returns its signal, log the intermediate outputs (technical indicators, fundamental metrics, sentiment scores) to a new Supabase table 'agent_task_outputs' with task_type field (forecast/risk/strategy). Implement a post-execution verifier function verify_agent_consistency() that checks if signals are internally consistent across tasks (e.g., if technical agent forecasts BUY with RSI>70 oversold but sentiment is negative, flag inconsistency score). This prevents fragmented evaluation and exposes generalization failures before synthesis.
