## Abstract

arXiv:2607.23006v1 Announce Type: new 
Abstract: Scientific question answering requires a retrieval system to solve two distinct problems: identifying which papers are relevant and locating the supporting evidence within those papers. Conventional retrieval-augmented generation typically addresses both through similarity search over fixed-length passages, flattening document structure and separating scientific claims from their methodological and argumentative context. We present VecTree-RAG, an agentic framework that assigns these tasks to complementary retrieval mechanisms. Vector search ranks compact document and section representations across the corpus, whereas reasoning-guided traversal of source-verified section trees localizes evidence within shortlisted papers. ## Proposed Change

Replace the current flat-passage pgvector retrieval in agents/historical_rag.py with a two-stage VecTree approach: (1) embed and store document-level (earnings call transcripts, annual reports) and section-level summaries (Management Discussion, Financial Highlights) as separate vectors in Supabase, (2) after vector search retrieves top-5 relevant documents, implement a tree-traversal function that progressively loads section text only after structural localization using Claude Haiku to guide which sections to expand based on the query. This preserves context (e.g., management commentary stays linked to the fiscal quarter) and reduces token waste by avoiding irrelevant section retrieval.
