## Abstract

Surveys the rapidly growing field of LLM-based agents applied to forecasting and prediction tasks, covering methods for training, fine-tuning, and evaluating forecasting agents across domains including finance, geopolitics, and science. Reviews benchmarks such as ForecastBench and agent architectures incorporating retrieval and tool use. Discusses evaluation pitfalls, contamination risks, and open challenges in deploying LLM forecasters in real-world settings.

## Proposed Change

Add a calibration scoring module to `governance/performance_tracker.py` that implements Brier Score and Expected Calibration Error (ECE) calculations on top of the existing outcome-vs-price accuracy tracking. Specifically, modify the `record_outcome()` function to store the synthesiser's confidence probabilities (derived from agent scores 0-100 normalised to 0-1) alongside actual outcomes, then add a weekly `compute_calibration_metrics()` function that buckets predictions into deciles, computes ECE and Brier Score per agent and in aggregate, and writes results to a new `calibration_metrics` Supabase table. This directly addresses the evaluation pitfalls flagged in the paper — raw accuracy metrics mask overconfident or underconfident forecasters, and ECE will reveal which agents (e.g. sentiment or macro) are systematically miscalibrated so their weights in the LangGraph orchestrator synthesis can be adjusted.
