## Abstract

arXiv:2607.18102v2 Announce Type: new 
Abstract: Financial question answering over U.S. Securities and Exchange Commission (SEC) filings requires retrieving and synthesizing heterogeneous evidence dispersed across long, standardized, and highly redundant disclosures. Existing retrieval-augmented and multi-agent systems typically derive retrieval queries directly from the user's question and rank candidates by semantic similarity. Together, these choices create prior-corpus misalignment: a mismatch between model priors and the target filings' structure, terminology, and evidence standards. As a result, query generation misses corpus-specific evidence, while semantic reranking favors topically similar but evidentially invalid false-positive chunks. Refactor agents/historical_rag.py to implement corpus-aligned query decomposition inspired by FinSAgent. Instead of directly embedding the user question, add a query_planner function that first identifies the relevant BSE/NSE filing sections (e.g., Annual Report Management Discussion & Analysis, Corporate Governance, Financial Statements) using a lightweight classification model (DistilBERT fine-tuned on 100 manually labeled Indian filings).
