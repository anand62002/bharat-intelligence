## Abstract

When language models revise a decision after another agent disagrees, neither reversal counts nor final accuracy shows whether they are fixing mistakes or abandoning correct answers. We introduce a controlled two-pass audit that holds the question, the evidence, and the model's initial answer fixed and varies only the revision context: neutral reflection, anonymous disagreement, or disagreement attributed to a domain expert. For binary decisions the accounting is exact: revision raises accuracy only if it is selective enough, reversing wrong answers more than a/(1-a) times as often as correct ones, where a is initial accuracy (nine times at 90%). ## Proposed Change

In the LangGraph orchestrator's synthesis step (orchestrator/synthesiser.py), add a 'prestige-blind revision guard' that strips agent identity/name labels before Claude Sonnet performs multi-agent disagreement reconciliation, then re-attaches them only for logging. Concretely, modify the `synthesise_signals()` function to build a `masked_agent_outputs` list where each dict has `agent_name` replaced with a neutral token (e.g. 'analyst_1'…'analyst_7') before passing to the Claude prompt, preventing Sonnet from over-weighting high-prestige agents (e.g. fundamental or macro) purely due to label authority. Additionally, add a `revision_selectivity_check()` helper that computes the ratio of wrong-to-right reversals across the weekly performance_tracker logs and raises a warning if the ratio falls below the threshold `a/(1-a)` (where `a` is current rolling accuracy), alerting the team that the model is capitulating to prestigious agents rather than making accurate corrections.
