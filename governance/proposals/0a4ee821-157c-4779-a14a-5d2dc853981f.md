## Abstract

arXiv:2607.18245v1 Announce Type: new 
Abstract: Exact-match evaluation of agent-calling obscures qualitatively different failure modes: a model may select the right function yet hallucinate argument values, or satisfy a schema while choosing a agent for the wrong reason. Existing benchmarks collapse these distinctions into a single binary score, leaving practitioners unable to diagnose where agent calls fail. We propose SAAG a cascaded diagnostic framework that decomposes agent-calling evaluation into three sequential stages: registry conformance, structural completeness, and argument grounding, each producing interpretable stage-specific diagnostics. ## Proposed Change

Add a cascaded validation layer in orchestrator/synthesis.py that decomposes each agent's response into three SAAG stages: (1) registry conformance (validate signal is BUY/HOLD/SELL/AVOID), (2) structural completeness (verify all required fields: score, detail, agent_name, data_sources exist and have correct types), (3) argument grounding (check score is 0-100, data_sources list is non-empty, detail dict contains expected keys per agent schema). On failure at any stage, return stage-specific error to the agent for one retry before fallback to HOLD/50 default, logging the failure mode for performance_tracker analysis.
