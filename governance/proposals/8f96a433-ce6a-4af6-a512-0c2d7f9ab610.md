## Proposed Change

Add a layer-specific validation chain in orchestrator/synthesis.py that checks each agent response against four fault layers before synthesis: (1) evidence_freshness (timestamp < 24h for technical/sentiment/institutional, verify Screener.in API call success for fundamental), (2) tool_contract (validate yfinance/feedparser/BeautifulSoup return schemas match expected fields), (3) data_provenance (log actual NSE/BSE/Screener.in URLs fetched vs. claimed sources in agent.data_sources), and (4) session_state (verify pgvector retrieval context matches current stock symbol). Emit per-layer pass/fail metadata alongside each agent signal before Claude Sonnet synthesis, enabling the fact_checker to attribute failures to specific layers rather than generic hallucination.
