## Abstract

Examines biases in LLM-based financial systems including lookahead bias, survivorship bias, and representation bias, with applications to trading systems and sentiment analysis for financial forecasting.

## Proposed Change

Add a survivorship bias detection layer in the historical_rag agent (agents/historical_rag.py) by creating a delisting_filter function that queries a new `delisted_stocks` table before similarity search. Insert logic in the `retrieve_similar_historical_patterns` function to flag when embeddings reference delisted/suspended stocks and down-weight those patterns by 50% in the final RAG score, preventing the system from learning only from 'winners' that survived.
