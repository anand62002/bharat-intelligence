## Abstract

Evaluates multiple LLM families (including GPT-4.1 and GPT-5) on real-world forecasting tasks from prediction markets (Polymarket, Metaculus, Kalshi), identifying a failure-mode taxonomy for when and why LLMs miscalibrate with contextual news inputs. Finds that reasoning-optimized models do not uniformly outperform standard models across all question categories, with contextual information introducing calibration divergence.

## Proposed Change

Add a `calibration_divergence_detector` function in `governance/hallucination_detector.py` that classifies each synthesised forecast by question-type taxonomy (quantitative/numerical, binary-event, comparative-ranking, causal-chain) before the weekly audit runs. For each category, compute a Brier score and ECE (Expected Calibration Error) separately using the `performance_tracker` outcome logs, then flag categories where ECE exceeds 0.15 as 'high-divergence' and emit a structured warning that the LangGraph orchestrator injects into the next synthesis prompt as an explicit prior-correction instruction (e.g. 'Note: sentiment-driven binary-event forecasts have shown calibration divergence — apply conservative confidence weighting'). This directly addresses the paper's finding that contextual news inputs cause category-specific miscalibration rather than uniform degradation, which is acutely relevant to Bharat Intelligence's sentiment agent feeding RSS NLP into Claude Sonnet synthesis.
