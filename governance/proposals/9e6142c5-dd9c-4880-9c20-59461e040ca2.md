## Abstract

arXiv:2610.14115v1 Announce Type: new 
Abstract: Large language models have significantly lowered the barrier to writing code. Naturally, this has also led to the development of data science agents that promise automating the design and execution of data science from task formulation to model development. Existing evaluations of agentic data science (agentic DS) assess downstream predictive performance and code correctness, providing preliminary insight in agentic DS capabilities. We argue that these evaluations overlook the fundamental principles of data science: methodological data science- and domain knowledge. ## Proposed Change

Add a DataLeakageValidator class in agents/validation.py that runs before each agent's final signal generation. It checks for temporal leakage (future data in features), target leakage (features derived from target), and train-test contamination. Each agent must call validator.check_features(df, target_col, timestamp_col) and append validation results to their response detail dict. This addresses the paper's core finding that existing agentic systems overlook methodological failures like data leakage.
