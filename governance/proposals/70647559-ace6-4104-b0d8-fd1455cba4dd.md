## Abstract

Investigates how orchestrating multiple specialized AI agents can mitigate hallucinations in generative AI models using Natural Language Processing for agent interactions.

## Proposed Change

Add a cross-agent claim verification layer in orchestrator/synthesis.py by implementing a post-synthesis validation step where each agent's factual claims (PE ratios, FII flows, technical indicator values) are cross-checked against at least one other agent's raw data before final signal aggregation. Create a new validate_cross_agent_claims() function that flags discrepancies >10% between agents citing the same data point (e.g., if fundamental agent reports PE=25 but sentiment agent's scraped news mentions PE=22), logs these to Supabase hallucination_audit table, and triggers a re-fetch from primary source (NSE/Screener.in API) before allowing the synthesis to proceed.

Reduce factual hallucinations in final synthesis by 40-60% as measured by weekly hallucination_detector audit comparing agent claims against ground-truth NSE/BSE data, particularly for numeric financial metrics where LLM confabulation is most detectable
