## YOUR TASK

**Bull Case** — Exactly 3 distinct reasons to be optimistic. Each must be specific, cite agent signals/scores or figures from the outputs above, and be relevant to the {horizon_days}-day horizon.

**Bear Case** — Exactly 3 distinct risks. Each must be specific and cite evidence from the agent outputs above.

**Synthesis** — One paragraph (2–4 sentences) that weighs the bull and bear cases, acknowledges key uncertainties, and explains why the decision above is (or is not) well supported. Cite only figures that appear in the agent outputs or the decision.

**Market constraints** — One sentence covering: (a) the NSE circuit-breaker band (±5% NIFTY 50/100 constituents, ±10% most EQ stocks, ±20% small-cap/SME/T-group); (b) liquidity (LIQUID / THIN / ILLIQUID); (c) any known ex-dividend or corporate-action date affecting T+2 settlement. **Headline** — One crisp clause (≤80 chars) summarising the thesis. Do not start with the action or include figures not in the decision; the "{action}: {symbol} —" prefix is added in code.

**Veto (optional)** — Set `veto` to true ONLY if the action is BUY and the agent outputs contain a concrete, material reason the rules cannot see (e.g. a governance red flag, a pending regulatory action, a data error that inflates the score).
